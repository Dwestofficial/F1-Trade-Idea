One-time Firebase Setup
To enable Google login, add your free Firebase config to this file. Takes ~3 minutes.
1
Go to console.firebase.google.com → Create a project
2
Authentication → Sign-in method → Enable Google
3
Firestore Database → Create database → Start in test mode
4
Project Settings → Your apps → Add web app → Copy firebaseConfig
5
In this HTML file, replace YOUR_FIREBASE_API_KEY etc. with your actual values at the top of the <script type="module"> block
6
Authentication → Settings → Authorized domains → Add your GitHub Pages URL: yourusername.github.io
🔒 Your Capital.com API key is stored encrypted in Firestore under your Google account UID. Nobody else can access it.
